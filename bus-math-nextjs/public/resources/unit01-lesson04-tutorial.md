# Lesson 04 Excel Table Tutorial

## Goal

Convert the Transactions range into an Excel Table named `LedgerTable`.

## Steps

1. Open `unit01-lesson04-student.xlsx`.
2. Confirm that the Transactions sheet has seven columns from A to G.
3. Confirm that the headers are Transaction ID, Date, Description, Account, Type, Debit, and Credit.
4. Select A1:G23. This range has 22 journal rows for 11 business events.
5. Select **Insert > Table**.
6. Select **My table has headers**.
7. Set the table name to `LedgerTable`.
8. Apply currency format to Debit and Credit.
9. Apply a date format to Date.
10. Filter Transaction ID to confirm that each ID has one debit row and one credit row.

## Check

- The table name is `LedgerTable`.
- All 22 journal rows are in the table.
- The table has no blank Account values.
- Each row has a debit or a credit, but not both.

Save the file. Lesson 05 uses this table to build the Trial Balance and Error Checks sheets.
